# SentinelPay brand kit

Colours: indigo #171A44, amber #E8920F, mint #43C9A4 (on light backgrounds use #1E9E7A), paper #F6F6FA.
Mark: a shield (trust) with a live pulse line (real-time risk checking).

| File | Use |
|---|---|
| `app-icon-1024.svg` / `png/app-icon-1024.png` | iOS App Store and master icon. Full-bleed square: the OS applies its own rounded corners, so do not pre-round it |
| `png/app-icon-{180,152,120,76}.png` | iOS device sizes |
| `png/app-icon-{512,192,48}.png` | Google Play listing (512), Android launcher fallback, small UI |
| `android-adaptive-foreground-432` + `android-adaptive-background-432` | Android adaptive icon layers (shield inside the 66% safe zone) |
| `android-monochrome-432.svg` | Android 13+ themed icon |
| `app-icon-light-1024.*` | light-mode alternate, store listings or marketing |
| `logo-mark-mono.svg` | single-colour mark; takes the surrounding text colour; for print, stamps, favicons |
| `logo-horizontal-dark.svg`, `logo-horizontal-light.svg` | website header, decks, documents |
| `social-banner-1200x630.*` | GitHub social preview, LinkedIn, link previews |
| `png/favicon-{32,16}.png` | browser favicons |

Notes
- Wordmark text in the SVGs uses font fallbacks (Inter, Helvetica, Arial). For print or trademark filing, convert text to outlines in a vector editor, or set the wordmark in your chosen typeface.
- The PNGs were drawn with the same geometry as the SVGs; the PNG banner uses a different font from the SVG banner.
- Clear space: at least the height of the pulse line around the mark. Minimum size: 16 px for the mark (the pulse stays legible down to 32 px; below that, use the mono mark).
- Trademark: nothing here has been searched or registered. Search the name "SentinelPay" in your markets before investing in branding.
